# 要件: バックアップ・復元 UI スタイル修正

## 背景

Spec 0004（バックアップ・リストア・メンテナンス機能のオーバーホール）の実行により、バックアップ関連UIに以下の退行（リグレッション）が発生した:

1. ボタンスタイルが filled（塗りつぶし）に変わり、旧バックアップタブで使われていた outline（枠線+アイコン付き）スタイルとの統一感が失われた
2. バックアップ先ディレクトリ名、最終バックアップ時刻、ファイル数を表示するカード型の情報パネルが消失した
3. バックアップの意義を説明するテキストが消失した
4. 「バックアップ・復元」セクションと「削除/初期化」セクションの間に視覚的な区切りがなく、誤操作リスクがある

## 要件一覧

### 1. ボタンスタイルの復元

- **1.1** バックアップ・復元セクションのボタンは、outline スタイル（背景透明・枠線あり・アイコン付き）で表示する
- **1.2** 「保存先にアクセスしてバックアップを実行」ボタン（保存先未設定→初回アクセス時）は primary の outline スタイルとする
- **1.3** 「バックアップ先を指定する」ボタンと「復元する」ボタンは secondary の outline スタイルとする
- **1.4** 保存先設定済み時の「バックアップを実行する」ボタンは primary の outline スタイルとする
- **1.5** ボタンにはアイコン（Material Symbols）を配置し、操作内容を視覚的に示す

### 2. 情報パネルの復元

- **2.1** 保存先設定済み時に「保存先」ラベルとディレクトリ名を表示する
- **2.2** 最終バックアップ時刻をカード形式で表示する（ラベル: `最終バックアップ時刻`、値: 日時）
- **2.3** ファイル数をカード形式で表示する（ラベル: `ファイル数`、値: `N 日分`）
- **2.4** 情報パネルは背景色・ボーダーで囲んだカード形式とし、内容が一目でわかるようにする

### 3. 説明テキストの復元

- **3.1** バックアップ・復元セクションの下部に、バックアップの意義を説明するテキストを表示する
- **3.2** 説明テキストは既存の翻訳キー `backup-description-new` を使用し、i18n 対応とする

### 4. セクション間の仕切り線

- **4.1** 「バックアップ・復元」セクションと「削除/初期化」セクションの間に `settings-divider` クラスの仕切り線 (`<hr>`) を配置する
- **4.2** 仕切り線は他のタブ（一般設定・カテゴリ等）で使用されている同一スタイルと統一する

### 5. 非機能要件

- **5.1** ダークテーマ時にも視認性が確保されること
- **5.2** 既存のメンテナンスタブの機能（削除/初期化、同期メンテナンス）に影響を与えないこと
- **5.3** 8言語すべてで表示が崩れないこと
