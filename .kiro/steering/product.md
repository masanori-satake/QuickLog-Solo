# QuickLog-Solo: 製品概要

## コンセプト
「1秒で記録、1秒で集計、1秒で安心」をコンセプトにした、個人向けサイドパネル作業メモツール。
高度な工数管理システムではなく、付箋にメモを書くような気軽さで作業時間を記録し、必要なときに即集計できる体験に特化している。

## 形態・配布
- **Chrome / Edge 拡張機能**（Manifest V3 / Side Panel API）
- Chrome Web Store または ZIP パッケージによる手動インストール
- Web 版（Vercel）でも動作するランディングページ・ガイドを同梱

## コア・フィロソフィー（4本柱）
1. **持続可能性 (Sustainability)** — 外部サーバー依存なし。オフライン完結。ブラウザ・タブが閉じても計測状態を復元できるレジリエンスを持つ。
2. **ミニマリズム (Minimalism)** — 必要十分な機能のみ。記録の摩擦を最小化。
3. **透明性 (Transparency)** — データは IndexedDB（ローカルのみ）。外部通信は CSP で遮断。`Local Only` バッジを UI に常時表示。
4. **長期保守性 (Longevity)** — 外部フレームワーク・ライブラリ一切不使用。Vanilla JS のみ。10年後も同じように動作・保守できる設計を目指す。

## 主要機能
- カテゴリ選択による作業タイマー開始・切り替え・終了・一時停止
- 日報コピー（Markdown / Wiki / HTML / CSV / TSV / Text、時刻丸め対応）
- タグごとの工数集計
- ローカルファイルバックアップ（File System Access API）
- 端末間同期 `chrome.storage.sync`（β版）
- アラーム・通知機能（平日・毎週・毎月など高度なスケジュール対応）
- 背景アニメーション（Web Worker によるサンドボックス実行）
- 8言語対応（en / ja / de / es / fr / pt / ko / zh）

## 非目標
- チーム管理・マルチユーザー
- 高度な分析レポート
- 外部サービス連携
- Firefox サポート（廃止済み）
